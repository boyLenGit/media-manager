## 2. 扫描 / 入库

| 功能 | 说明 | 入口 |
|---|---|---|
| 扫描路径管理 | 增删改扫描目录,填**容器内路径** | 设置→扫描路径 |
| 挂载点提示 | 自动探测容器挂载点,输入框提示可填什么 + 候选 chips | ScanPathsTab 问号 popover |
| 三阶段扫描 | 扫描文件 → ffprobe+缩略图 → 全库去重 | 点"扫描"按钮 |
| 实时进度 | 进度条区分阶段:`扫描 X/Y → 后处理 X/Y → 查重 X/Y` | 扫描任务列表 2s 轮询 |

**扫描三阶段**(`scan_service.py`,是重点特性):
1. **scanning**:os.walk 列文件 → upsert file_asset → 建 media_item/media_file
2. **enriching**:ffprobe 探测编码 + ffmpeg 生成缩略图(并发 2,每个完成实时刷 `enrich_done`)
3. **dedup**:全库重复检测(**只在没有其他 pending/running job 时跑**,避免多路径扫描重复跑 O(n²))

接口:`POST /api/scan/paths/{id}/scan`、`GET /api/scan/jobs`、`GET /api/scan/mounts`

## 9. 重复检测

| 层级 | 判据 | 误判率 |
|---|---|---|
| **exact** | partial_hash + size 完全相同 | 极低 |
| **high** | normalized_title 完全相同 | 低 |
| **medium** | 标题 Levenshtein ≥ 90% | 中 |

- **自动**:扫描第三阶段自动跑,结果在 Dashboard 显示黄条提示
- **手动**:重复检测页,可调相似度阈值
- **操作**:整组合并(文件改挂到保留项)/ 单个移除(admin)
- **大库优化**:第 3 轮用 normalized_title 前 2 字分桶,O(n²)→O(bucket²)

接口:`GET /api/library/duplicates`、`POST /api/library/duplicates/merge`、`.../delete`

## 10. 危险区 + 审计(安全)

| 功能 | 说明 |
|---|---|
| **抹掉所有内容** | 设置→危险区,大红按钮 → 弹窗输**管理员密码**(bcrypt 服务端校验)→ 清空除当前 admin 外所有数据 → 强制重新登录 |
| 保护 | 不动磁盘视频文件、不删当前 admin、audit_log 不被清 |
| **审计日志** | 设置→审计日志,记录 reset_all / media_delete / duplicates_merge / duplicates_delete,含操作人/IP/时间/详情 |

接口:`POST /api/settings/reset-all`(要 password)、`GET /api/settings/audit-log`

设计意图:用户"新建用户名字打错了想重来"这类场景,提供彻底但安全的重置。
