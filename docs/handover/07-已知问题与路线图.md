## C. 环境相关的"非 bug"(用户实际遇到的)

这些不是代码问题,是部署环境限制,记下来避免下次误判:

| 现象 | 真因 | 结论 |
|---|---|---|
| **qB 下载卡 0%,BitComet 能下** | NAS 出站到大部分 BT tracker 端口被运营商屏蔽;BitComet 走自家 HTTP 镜像/长效种子库绕过 | 非 bug,详见 08。qB 走代理可缓解 |
| **NAS docker pull ghcr.io/docker.io 卡死** | 老 docker + CDN 国内不友好 | 走方案 C(外部拉+scp) |
| **复制路径"复制失败"** | HTTP 页面下 navigator.clipboard 不可用 | 已修(execCommand fallback) |
| **/volume1/sys 容器读不了** | 群晖 ACL | 已修(docker_boy_auto 组 + group_add) |
